## Resumo

Terceira etapa do painel de configuração: os 4 painéis de
configuração passam a existir visualmente na TUI (`--tui`), sobre o
catálogo (v1.21.0) e os comandos `SET`/`SETTINGS`/`DIALECT` do CLI
(v1.22.0).

## O que tem nesta release

- Menu **Setup** ganha 4 itens novos, um por painel: **Basic
  Dignified** (numeração de linha, cabeçalho REM, TAB, etc.), **MSX**
  (conversões de `PRINT`/`THEN`/`GOTO`, tokenizer, emulador openMSX),
  **ZX81** e **ZX Spectrum** (tokenizer de fita, emulador EightyOne,
  modelo de ROM).
- Cada painel abre um formulário com todas as opções daquela
  categoria, já com os valores atuais — checkbox para opção
  verdadeiro/falso, lista suspensa para opções de escolha fixa, campo
  numérico para números, campo de texto livre para o resto — e
  botões **Apply**/**Cancel**.
- 1 teste novo de ponta a ponta, usando um terminal simulado.

## O que não mudou / ainda falta

- O mesmo painel na interface gráfica (GUI) ainda não existe —
  próxima etapa.
- Nenhum valor configurado aqui ainda é lido por um comando de
  conversão real.
