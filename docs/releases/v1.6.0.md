## Resumo

Primeira conversão Dignified→Classic de verdade produzindo texto
correto: `Parser` MSX Pass 3 e Pass 4 — a alocação de variáveis de 2
letras.

## O que tem nesta release

- Novo `internal/platforms/msx/parser.go`: aliases de 2 letras pra
  variáveis longas, descendente de `zz`; nome já curto fica
  inalterado; `~nome` fica mantido por extenso; erro fatal ao esgotar
  os 676 aliases ou usar `~` incorretamente.
- Corrigida a interface `core.Parser`: cada pass agora recebe a lista
  inteira de tokens da pass + o índice atual (lookback), não só o
  token isolado.
- Teste de ponta a ponta confirmando `counter=0` → `zz = 0`.

## O que não mudou / ainda falta

- Pass 1 (separador de chamada Dignified), Pass 5 (`?`/PRINT,
  `THEN`/`GOTO`, `TRUE`/`FALSE`, tradução Unicode) e um `generate()`
  de verdade (espaçamento, limite de linha).
- Ligar isso ao tokenizer já pronto (`internal/platforms/msx/tokenizer.go`)
  pra fechar o caminho completo até o binário.

## Pacote

`goBaDig-v1.6.0.zip`: executável Windows, `README.md`, `CHANGELOG.md`,
`LICENSE`, `docs/MANUAL.md`, `docs/RESOURCES.md`, `examples/`. O
