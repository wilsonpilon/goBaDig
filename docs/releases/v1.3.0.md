# goBaDig v1.3.0 — "NEW" / core-engine (build 0)

**Data**: 2026-11-21
**Bloco (`X`)**: `NEW`
**Feature (`Y`)**: `core-engine`
**Build (`Z`)**: `0`

## Resumo

Primeiro código do motor de conversão de BASIC. Até aqui, tudo em
goBaDig era infraestrutura/interface (CLI/TUI/GUI, temas, editor) —
nenhuma linha de BASIC foi convertida ainda. Esta release começa o
núcleo do motor propriamente dito (Bloco 1 do `OUTLINE.md`): **ainda
não há nenhum dialeto real (MSX/ZX81/ZX Spectrum) usando isso**, e
nenhum comando de conversão está disponível para o usuário final.

## O que tem nesta release

Novo pacote `internal/core`:

- `Token`/`Position`/`TokenKind` — unidade e posição léxica.
- `HookAction` (`Continue`/`Skip`/`Replace`) — substitui o protocolo
  tri-estado (`False`/`None`/`Token`) do motor Python original por um
  enum explícito.
- Diagnóstico/erro (`Diagnostic`, `DiagnosticSink`) — substitui o
  `Infolog` original; erro sobe a pilha como `error` Go, sem o exit
  code silencioso guardado como atributo de classe mutável.
- `CompileContext`/`SymbolTables` — estado explícito por parâmetro, em
  vez de atributos dinâmicos de instância.
- Alocador de variáveis por categoria, genérico e descendente —
  generaliza MSX (2 letras), ZX81 (1 letra) e ZX Spectrum (nativo + 1
  letra por categoria) sob o mesmo mecanismo.
- Interfaces "v0" `Description`/`Lexer`/`Parser`/`Settings` e o struct
  `Platform` que as agrupa — equivalente Go ao trio dinamicamente
  importado `Classic`/`Tools`/`Dignified` do motor original (Go não
  tem esse truque de reatribuição de módulo).
- Driver do pipeline (`Lex`→`Parse`→`Generate`→`Run`), validado de
  ponta a ponta contra uma **plataforma fictícia mínima** (não é MSX
  de verdade — só reconhece `PRINT`/inteiros) antes de qualquer
  dialeto real depender do contrato. `Parse` já respeita o mesmo gate
  do motor original: os passes 4 e 5 só rodam no arquivo principal,
  nunca em arquivos trazidos por `INCLUDE`.

## O que não mudou / ainda falta

- Nenhum vocabulário real de dialeto (palavras-chave, números,
  strings) — o scanner de hoje só reconhece espaço em branco e fim de
  linha. Isso é trabalho do Bloco 2 (módulo MSX).
- `Expose`/`Tools.Interface` (só importam com um CLI real de flags,
  Bloco 5), `INCLUDE` recursivo de verdade, o caminho `-asc`, e a
  resolução de fato das 4 camadas de config (SQLite global < projeto <
  CLI < remtags) — `CompileSettings` é só um placeholder por ora.
- Ver `OUTLINE.md`, Bloco 1, para o detalhamento completo por fase.

## Pacote

`goBaDig-v1.3.0.zip`: executável Windows, `README.md`, `CHANGELOG.md`,
`LICENSE`, `docs/MANUAL.md`, `docs/RESOURCES.md`, `examples/`. O
binário não muda de comportamento nesta release — `internal/core`
ainda não é usado por nenhum outro pacote.
