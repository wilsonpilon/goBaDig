# goBaDig v1.2.0 — "NEW" / themes (build 0)

**Data**: 2026-11-21
**Bloco (`X`)**: `NEW`
**Feature (`Y`)**: `themes`
**Build (`Z`)**: `0`

## Resumo

Acumula tudo que ficou pronto desde a `v1.1.4` sem um release
publicado: temas persistidos nas três interfaces, a TUI redesenhada no
visual retrô Turbo Vision/Norton Commander (com o bug real de
"congelamento" do `Setup > Install` encontrado e corrigido), e o
editor **WibEdit** integrado à TUI como base da futura IDE do goBaDig.

## O que tem nesta release

- **Temas**: catálogo de seis temas (VS Code Dark, Dracula, Monokai,
  Nord, Solarized Light, Gruvbox Dark) para GUI, TUI e CLI, cada
  interface com sua própria seleção persistida em SQLite
  (`modernc.org/sqlite`, sem CGO). `Setup > Install` (TUI/GUI) e
  `theme <nome>` (CLI) trocam o tema na hora.
- **TUI redesenhada** no visual retrô MS-DOS anos 1990 (Turbo Vision/
  Turbo Pascal/Norton Commander): janelas com borda dupla, caixa de
  sistema `[■]`, sombra projetada, ícones Unicode nos menus
  (`▭ File`, `✎ Editor`, `⚙ Setup`, `ℹ Help`), desktop com textura
  pontilhada e banner central.
- **Corrigido o congelamento real de `Setup > Install`**: nunca foi um
  deadlock — era o diálogo de temas inteiro ficando invisível por um
  bug clássico de Go (`.SetBackgroundColor(...)` encadeado num
  `*tview.Grid` retornando `*tview.Box`, método herdado sem override).
  Dois testes de regressão novos garantem que não volta.
- **Editor WibEdit integrado**: editor de texto/código estilo
  WordStar/Norton Editor 2 (portado do projeto `wibworks` do mesmo
  autor), embutido na TUI via **`Editor > Open`** — não é um binário
  separado. Base da futura IDE do goBaDig; ainda não ligado a nada
  específico de BASIC.
- **Console `--cli`**: conclusão interativa de comandos e temas com
  `Tab` (um segundo `Tab` lista as alternativas).
- `current/`: convenção nova de build local sempre atualizado para
  teste manual, documentada em `CLAUDE.md`.
- Investigação de viabilidade do **ZRCP** (ZEsarUX) para monitoramento
  de erro em tempo real em ZX81/ZX Spectrum — confirmada como viável
  (ver `OUTLINE.md`, Bloco 0), ainda não implementada.
- Gerados os vetores de ouro do tokenizer MSX (13 casos) — o módulo
  MSX não tinha suíte de testes no projeto Python original, diferente
  de ZX81/ZX Spectrum.
- `build.ps1`: automação de build local completo (deps, testes,
  pacote `dist/goBaDig-vX.Y.Z.zip`).

## O que não mudou

- Nenhuma conversão de BASIC, tokenizer ou integração de emulador real
  está implementada ainda. O primeiro código do motor de conversão
  chega na release seguinte (`v1.3.0`).

## Pacote

`goBaDig-v1.2.0.zip`: executável Windows, `README.md`, `CHANGELOG.md`,
`LICENSE`, `docs/MANUAL.md`, `docs/RESOURCES.md`, `examples/`.
