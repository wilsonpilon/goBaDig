## Resumo

**Autocomplete no WibEdit**, primeira metade do próximo passo já
anunciado na v1.46.0 ("depois vamos usar o autocomplete e o help
sensível ao contexto"). Antes de implementar, o usuário pediu pra dar
uma olhada no MSXIDE (projeto próprio dele, em FreeBASIC) pra estudar
como ele já resolve help/autocomplete/man — confirmado que a
arquitetura é reaproveitável como conceito (popup por prefixo, mesma
fonte de dados do destaque de sintaxe), mas não há código Go a portar.
Decisão de escopo desta rodada: usar só as tabelas de palavra-chave/
função já existentes (destaque de sintaxe, v1.46.0), sem dicionário
externo ainda — isso fica para uma rodada futura.

## O que mudou

- `internal/editor/autocomplete.go`: popup de autocomplete por
  prefixo, ancorado na palavra sendo digitada. Reusa as mesmas tabelas
  de palavra-chave/função do destaque de sintaxe como única fonte de
  candidatos. `Tab`/`Enter` completa, `Up`/`Down` navega, `Esc` fecha
  sem completar; qualquer outra tecla (espaço, pontuação, setas
  esquerda/direita, Backspace) cai no fluxo normal do editor e a lista
  se atualiza ou fecha sozinha a partir do novo estado do cursor/texto.
- `Editor.Capture` ganhou um terceiro modo de interceptação de tecla:
  nem "passa tudo" nem "bloqueia tudo" (os dois já existentes) — só as
  cinco teclas acima são roubadas enquanto o popup está aberto.

## Corrigido no caminho (achado implementando, não planejado)

Uma primeira versão do popup usava o mesmo mecanismo do menu suspenso
(`editorDropdown`): uma página nova em `tview.Pages`. Isso quebrava a
digitação por completo depois do popup abrir uma vez — causa raiz:
`tview.Pages.AddPage` rouba o foco pra página recém-adicionada sempre
que o container já tem foco, e `*tview.Box` não tem `InputHandler`
próprio, então toda tecla seguinte era engolida em silêncio. Corrigido
abandonando `Pages` pro popup: `Editor` ganhou um método `Draw` próprio
que desenha o popup diretamente por cima, sem nunca criar uma página
nem tocar foco.

## Validação

- `internal/editor/autocomplete_test.go`: popup abre com o candidato
  certo (MSX/ZX81/ZX Spectrum), `Tab` confirma e substitui o prefixo,
  `Esc` fecha sem alterar o texto, espaço fecha sozinho, setas navegam
  entre várias opções com wrap-around, nunca abre num documento sem
  dialeto reconhecido.
- `go build`/`go vet`/`gofmt`/`go test ./...` limpos no repositório
  inteiro.
