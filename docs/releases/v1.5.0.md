# goBaDig v1.5.0 — "NEW" / msx-lexer (build 0)

**Data**: 2026-11-21
**Bloco (`X`)**: `NEW`
**Feature (`Y`)**: `msx-lexer`
**Build (`Z`)**: `0`

## Resumo

`Description` e `Lexer` MSX portados de verdade — o primeiro uso real
das interfaces "v0" do motor (`internal/core`, Bloco 1), que até aqui
só tinham sido validadas contra uma plataforma fictícia.

## O que tem nesta release

- Novo `internal/platforms/msx/description.go`: vocabulário MSX
  completo (instruções, funções, operadores, símbolos).
- Novo `internal/platforms/msx/lexer.go`: classifica texto Dignified
  MSX em tokens — palavras-chave, operadores, símbolos, números
  (decimal/`&H`/`&O`/`&B`), comentários, `DATA`.
- Corrigida a interface `core.Lexer`: agora recebe a linha inteira
  restante (não uma palavra pré-cortada), suportando números com
  notação científica e símbolos compostos sem espaço.

## O que não mudou / ainda falta

- Nenhuma conversão Dignified→Classic completa ainda — falta o
  `Parser` MSX (5 passes, alocação de variáveis).
- Bloco de comentário `''` multi-linha, semântica literal do `DATA`,
  tradução Unicode→ASCII: adiados para o `Parser` (Pass 5).

## Pacote

`goBaDig-v1.5.0.zip`: executável Windows, `README.md`, `CHANGELOG.md`,
`LICENSE`, `docs/MANUAL.md`, `docs/RESOURCES.md`, `examples/`. O
binário não muda de comportamento nesta release.
