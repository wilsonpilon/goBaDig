## Resumo

Resolução de labels e numeração de linha — a peça que faltava pra
qualquer programa Dignified real (mesmo o mais simples, com um `GOTO
{algumlugar}`) compilar de ponta a ponta. Validada contra um exemplo
real completo (`CGK173.dmx`, "Change Graph Kit") que o usuário
apontou no repositório `badig/examples/msx`.

## O que tem nesta release

- `{nome}` no início de linha é declaração; em qualquer outro lugar é
  referência de salto; `{@}` aponta pra linha atual.
- Label nunca gasta linha própria — "cola" na próxima linha com
  conteúdo real.
- Linhas em branco somem sem gastar número; `_` no fim de linha funde
  com a linha seguinte numa só linha numerada.
- Erro fatal ao saltar pra um label não declarado.
- `internal/core` passou a fazer trabalho Dignified de verdade antes
  de delegar pra plataforma — a primeira vez que isso acontece de
  fato, não só documentado como intenção.

## O que não mudou / ainda falta

- Loop labels (`nome{ ... }`/`exit`), inserção de header, relatório
  de labels (`-lbr`).
- `DEFINE`/`FUNC`/`RET`/`INCLUDE`/`KEEP`/`DECLARE`.
- Pass 1 (`_` fora do fim de linha) e um `generate()` de verdade
  (espaçamento por palavra reservada, limite de linha).
