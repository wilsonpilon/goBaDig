## Resumo

`Parser` MSX Pass 5 — as 5 conversões finais específicas do Classic,
fechando as conversões de token-para-token do `Parser`.

## O que tem nesta release

- `?`/`PRINT` convertível nos dois sentidos, strip de `THEN` antes de
  `GOTO` (ou `GOTO` depois de `THEN`/`ELSE`), expansão de atribuição
  composta/incremento/decremento (`x+=5`→`x = x + 5`, `x++`→
  `x = x + 1`), `TRUE`/`FALSE`→`-1`/`0`, tradução Unicode→ASCII de
  caracteres literais.
- Corrigida a interface `core.Parser`: o payload de `Replace` virou
  `[]Token` (não mais `Token`), permitindo um pass expandir 1 token em
  vários.
- `core.Lex()` reconhece `TRUE`/`FALSE` como operadores Dignified
  compartilhados.

## O que não mudou / ainda falta

- Pass 1 (separador de chamada Dignified `_`) — ainda não está claro o
  que esse recurso deveria gerar no texto Classic final.
- Um `generate()` de verdade (espaçamento por palavra reservada,
  limite de 256 chars/linha).
- Ligar isso ao tokenizer já pronto (`internal/platforms/msx/tokenizer.go`)
  pra fechar o caminho completo até o binário.

binário não muda de comportamento nesta release.
