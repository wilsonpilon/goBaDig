## Resumo

Esta é a **release inicial do goBaDig** — "nossa partida". Não existe
ainda nenhuma linha de código Go funcional: esta versão marca o fim da
fase de análise do projeto Python original (*Basic Dignified Suite*) e
o início formal do repositório, com toda a arquitetura, o escopo e a
divisão de trabalho documentados e versionados.

## O que tem nesta release

- **`OUTLINE.md`** — plano vivo de arquitetura: pipeline do motor
  original, contrato de extensão por plataforma, inventário técnico
  detalhado de MSX/ZX81/ZX Spectrum, decisões de arquitetura propostas
  para o Go, divisão do trabalho em 11 blocos com peso/prioridade, e
  perguntas em aberto para decisão do usuário.
- **`README.md`** — apresentação do projeto, plataformas suportadas,
  ferramentas/tecnologias planejadas, créditos.
- **`CHANGELOG.md`** — este histórico, com o esquema de versionamento
  `X.Y.Z` explicado.
- **`docs/MANUAL.md`** — manual de uso (requisitos, download,
  compilação, execução, testes, editores); a maior parte ainda marcada
  "(pendente)" até existir código.
- **`docs/RESOURCES.md`** — lista de recursos externos necessários
  (emuladores, ROMs, fontes) com onde baixar e onde colocar em
  `resource/` ao montar o ambiente em outra máquina.
- Estrutura de diretórios: `dist/`, `resource/` (ambos fora do controle
  de versão, exceto um `README.md` cada), `examples/` (com subpastas
  `msx/`, `zx81/`, `zxspectrum/`), `docs/releases/`.

## Escopo confirmado nesta release

- **Plataformas**: MSX, ZX81, ZX Spectrum. CoCo **não** é suportado.
- **Emuladores alvo**: openMSX e fMSX (MSX); EightyOne, ZEsarUX e
  sz81/XZ81 (ZX81); EightyOne, Spectaculator e ZEsarUX (ZX Spectrum).
  O ZEsarUX tem um protocolo de controle remoto (ZRCP) que é candidato
  a viabilizar monitoramento de erro em tempo real também em
  ZX81/Spectrum — algo que hoje só existe para MSX via openMSX.
- **Formatos de mídia alvo**: `.BMX` + `.CAS`/`.DSK` (MSX); `.p` +
  `.81`/`.p81` (ZX81); `.TAP`/`.TZX`/`.Z80`/`.SNA` + `.DSK` +3 opcional
  (ZX Spectrum).
- **Editores**: VSCode (prioridade 1, VSIX único para os três
  dialetos), Sublime Text (prioridade 2). Um editor próprio baseado no
  Norton Editor 2.0 é mencionado como visão de longo prazo, mas fica
  **fora de escopo por enquanto**. Notepad++ e UltraEdit ficam como
  alvos opcionais, "se for possível".
- **Versionamento**: esquema próprio `X.Y.Z` (não é SemVer tradicional),
  descrito no `CHANGELOG.md`.

## Observações e pendências conhecidas

- Vários arquivos de documentação do projeto Python original têm
  marcadores de merge conflict não resolvidos entre os branches ZX81 e
  ZX Spectrum — ver `OUTLINE.md`, seção 2.
- O diretório `badig/` (projeto Python original, mantido como
  referência/oráculo de testes) permanece fora do controle de versão
  deste repositório por enquanto — decisão deliberadamente não tomada
  nesta release.
- Nenhum binário é distribuído nesta release — o zip anexado contém
  apenas a documentação de planejamento, para fins de registro histórico
  do ponto de partida do projeto.
