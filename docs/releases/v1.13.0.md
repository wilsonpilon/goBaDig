## Resumo

`KEEP` — compilação condicional via tags `#tag`, usada no
`CGK173.dmx` ("Change Graph Kit").

## O que tem nesta release

- `KEEP #tag1 #tag2 ...` declara quais tags ficam no código final;
  sem `KEEP` nenhum, todo bloco com tag é removido por padrão (são
  extras opt-in). `#ALL` mantém qualquer tag; `#NONE` sobrepõe
  qualquer outra tag mantida.
- `#tag` sozinho numa linha abre/fecha um bloco removido (ou mantido)
  inteiro; `#tag resto da linha` remove/mantém só aquela linha.
- `#` continua funcionando normalmente como símbolo de canal de
  arquivo do MSX (`PRINT #1`, `OPEN...AS #1`) — um lookahead no
  `Lexer` evita o conflito com a nova tag `#a`/`#none`/`#all`.

## O que não mudou / ainda falta

- `INCLUDE`.
- Pass 1 (`_` fora do fim de linha) e um `generate()` de verdade
  (espaçamento por palavra reservada, limite de linha).
