## Resumo

Primeira etapa de um recurso novo, pedido pelo usuário: um
gerenciador de arquivos de dois painéis (estilo Norton Commander/PC
Tools) cujo uso principal é criar e editar imagens de disquete
`.DSK` do MSX. Esta release entrega só a base: a biblioteca que lê e
escreve esse formato.

## O que tem nesta release

- Pacote novo `internal/platforms/msx/dsk`, com uma API completa
  pra manipular imagens `.DSK` (MSX-DOS/FAT12): `Create` (formata um
  disco novo de 720KB), `Open`, `Close`, `ListFiles`, `AddFile`,
  `ExtractFile`, `DeleteFile`.
- Porta direta de `E:\msxdiskutil\MSXDisk.pbi` — a reescrita em
  PureBasic, feita pelo próprio usuário, do utilitário original em C
  (`rddsk`/`wrdsk`, por Arnold Metselaar) que já lê/escreve esse
  formato corretamente.
- Validado contra um disco `.DSK` real: os arquivos extraídos batem
  **byte a byte** contra os arquivos de referência originais.
- 14 testes automatizados novos.

## O que não mudou / ainda falta

- Nenhuma interface de usuário ainda — a navegação de dois painéis
  na TUI (e depois na GUI) e as operações de arquivo a partir dela
  (adicionar/extrair/apagar/criar disco) são as próximas etapas.
- Nenhum valor gerado por essa biblioteca é consumido pelo fluxo de
  conversão/empacotamento automático ainda — isso é um passo futuro
  separado.
