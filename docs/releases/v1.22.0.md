## Resumo

Segunda etapa do painel de configuração: comandos `SET`/`SETTINGS`/
`DIALECT` no console interativo do CLI (`--cli`), sobre o catálogo e
o schema SQLite entregues na v1.21.0 (Etapa A).

## O que tem nesta release

- `set <OPÇÃO>` (sem valor) mostra o valor atual; `set <OPÇÃO>
  <VALOR>` valida contra o catálogo (`internal/options`) e grava
  (ex.: `set INITIAL_LINE 1`, igual ao exemplo original pedido).
- `settings` lista todas as opções de **Basic Dignified** mais as do
  dialeto atual da sessão.
- `dialect <nome>` troca entre `msx`/`zx81`/`zxspectrum` — necessário
  porque várias opções repetem nome entre dialetos (`TOKENIZE`,
  `EMULATOR_RUN`, `EMULATOR_PATH`), cada um com seu próprio valor.
  Opções de **Basic Dignified** são sempre resolvidas primeiro,
  independente do dialeto atual.
- Todo comando do console agora casa **case-insensitive** (`SET
  INITIAL_LINE 1` funciona igual a `set initial_line 1`) — aplicado a
  todos os comandos existentes, não só o novo `set`.
- Tab-completion para `dialect <nome>`.
- 13 testes novos.

## O que não mudou / ainda falta

- Nenhum painel de configuração na TUI/GUI ainda (Etapas C e D).
- O dialeto escolhido com `dialect` só vale pra sessão atual do
  console — não é persistido.
- Nenhum valor configurado aqui é lido pelo pipeline de conversão
  real ainda.
