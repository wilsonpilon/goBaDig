# goBaDig v1.1.4 — "NEW" / outline (build 4)

**Data**: 2026-11-05
**Bloco (`X`)**: `NEW`
**Feature (`Y`)**: `outline`
**Build (`Z`)**: `4` — modo console interativo.

## Resumo

O usuário perguntou como entrar num modo CLI com um prompt esperando
comandos — esse modo ainda não existia no stub. Esta release adiciona
`goBaDig --cli`: um console de verdade, que fica aguardando comandos do
usuário até `exit`/`quit` ou `Ctrl-D`, fechando a paridade entre as três
interfaces (`--cli`, `--tui`, `--gui` — cada uma agora com seu modo
interativo dedicado).

## O que tem nesta release

- `goBaDig --cli` abre um prompt `goBaDig> `.
- Comandos disponíveis nesta versão: `help` (mesma saída do `--help`),
  `man` (mesma saída do `--man`), `about`, `version`, `exit`/`quit`.
  Comando desconhecido avisa e mantém o console aberto.
- Encerra também em fim de entrada (`Ctrl-D`/`Ctrl-Z`), sem travar.
- Testes automatizados cobrindo a saída esperada e a parada limpa em
  EOF, além de teste manual via pipe de comandos.

## O que não mudou

- Nenhuma conversão de BASIC, tokenizer ou integração de emulador está
  implementada ainda — o console só tem os mesmos comandos de
  ajuda/identidade que já existiam como flags. Comandos reais chegam
  junto com o motor (Blocos 1-4 do `OUTLINE.md`).
- TUI e GUI não mudaram nesta release.
