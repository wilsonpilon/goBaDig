# goBaDig v1.25.0 — "NEW" / tui-menu-colors (build 0)

**Feature (`Y`)**: `tui-menu-colors`
**Build (`Z`)**: `0`

## Resumo

Correção de um bug de cor no menu suspenso da TUI, reportado
diretamente pelo usuário assim que o menu `Setup` passou a ter itens
de verdade de sobra (os 4 painéis de configuração da release
anterior) pra revelar o problema.

## O que foi corrigido

- Um item **não selecionado** de um menu suspenso aberto renderizava
  com texto preto em fundo preto — invisível, em qualquer tema — até
  o usuário navegar até ele.
- O destaque do item **selecionado** não preenchia a largura inteira
  do menu: parava exatamente no fim do próprio texto, deixando o
  resto da linha com a cor de fundo comum, um efeito visual feio e
  inconsistente com o estilo retrô (PC Tools 9/Norton Utilities 9)
  que a TUI busca.
- 2 testes novos de ponta a ponta, usando um terminal simulado,
  confirmados contra o bug real (revertido temporariamente) antes de
  escrever a versão corrigida.

## O que não mudou

Nenhum comando de conversão real existe ainda em nenhuma interface —
esta release é puramente visual/de correção.
