## Resumo

Primeiro **programa real** do goBaDig: um **stub** que compila, roda e
já tem CLI, TUI e GUI com paridade de menu entre as três interfaces.
Ainda não há conversor, tokenizer ou integração com emulador — isso
continua nos Blocos 1-4 do [`OUTLINE.md`](../../OUTLINE.md).

## O que tem nesta release

- **CLI** (`goBaDig --help` / `--man`): lista de opções e uma referência
  estilo `man` do Unix (nesta versão, só o "about" do projeto — o `man`
  completo, com as opções do BaDig e os manuais de sintaxe BASIC do
  MSX/ZX81/ZX Spectrum, vem depois).
- **TUI** (`goBaDig --tui`, `tview`/`tcell`): menu `File > Exit` e
  `Help > About`.
- **GUI** (`goBaDig --gui`, Fyne): janela com o mesmo menu
  `File > Exit` / `Help > About` (diálogo nativo).
- As três interfaces compartilham o mesmo texto "about" — princípio de
  paridade de opções registrado no `OUTLINE.md`.

## Decisões registradas nesta release

- O sistema de ajuda final terá dois níveis na CLI: `--help` (opções) e
  um `man` completo (funções/opções do BaDig + manuais de sintaxe BASIC
  das três plataformas). TUI e GUI terão ajuda tradicional
  (`Help > About`, depois um visualizador do mesmo manual).
- Material de referência já existente do usuário, a reaproveitar
  futuramente: `fwMSX` (manual MSX), `go81` (manual ZX81),
  `paleobasic`/`msxide` (implementações prontas do Norton Editor — TUI
  e GUI). Nenhum foi lido nesta sessão; localizações a confirmar com o
  usuário quando o trabalho começar.
- O editor próprio baseado no Norton Editor 2.0 **continua fora de
  escopo de implementação** — só mencionado/documentado, como pedido.
- `badig/` (projeto Python original) está confirmado como **nunca
  commitado** neste repositório — serve só de referência local.
